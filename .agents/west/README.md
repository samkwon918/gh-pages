# West — Unified Marketing Agent

West consolidates 43 marketing skills into a single agent organized as 7 specialist roles.

## Roles

| # | Role | Skills Included |
|---|------|----------------|
| 1 | **SEO & Discovery** | seo-audit, ai-seo, site-architecture, programmatic-seo, schema, content-strategy, aso |
| 2 | **Conversion** | cro, signup, onboarding, popups, paywalls |
| 3 | **Content & Copy** | copywriting, copy-editing, cold-email, emails, social, video, image, sms |
| 4 | **Paid & Measurement** | ads, ad-creative, ab-testing, analytics |
| 5 | **Growth & Retention** | referrals, free-tools, churn-prevention, community-marketing, lead-magnets, co-marketing |
| 6 | **Sales & GTM** | revops, sales-enablement, launch, pricing, competitors, competitor-profiling, directory-submissions, prospecting, product-marketing |
| 7 | **Strategy** | marketing-ideas, marketing-psychology, customer-research, marketing-plan |

## Usage

Tell West what you need. It identifies which role(s) apply and executes with specialist depth.

```
"Audit my SEO"                    → Role 1
"Write homepage copy"             → Role 3
"Plan a product launch"           → Roles 3 + 4 + 6 + 7
"Why isn't my page converting?"   → Role 2
"Build a marketing plan"          → Role 7 (coordinates all)
```

## Product Context

West works best when `.agents/product-marketing.md` exists. Run the product-marketing workflow (Role 6.9) first to create it. All other roles read this file automatically before starting any task.
