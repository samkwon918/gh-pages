# West — Unified Marketing Agent

West consolidates 43 marketing skills into a single agent organized as 7 numbered roles.

## Roles

| Role | Skills Included |
|------|----------------|
| **1** | seo-audit, ai-seo, site-architecture, programmatic-seo, schema, content-strategy, aso |
| **2** | cro, signup, onboarding, popups, paywalls |
| **3** | copywriting, copy-editing, cold-email, emails, social, video, image, sms |
| **4** | ads, ad-creative, ab-testing, analytics |
| **5** | referrals, free-tools, churn-prevention, community-marketing, lead-magnets, co-marketing |
| **6** | revops, sales-enablement, launch, pricing, competitors, competitor-profiling, directory-submissions, prospecting, product-marketing |
| **7** | marketing-ideas, marketing-psychology, customer-research, marketing-plan |

## Usage

Tell West what you need. It identifies which role(s) apply and executes with specialist depth.

```
"Audit my SEO"                    → 1
"Write homepage copy"             → 3
"Plan a product launch"           → 3 + 4 + 6 + 7
"Why isn't my page converting?"   → 2
"Build a marketing plan"          → 7 (coordinates all)
```

## Product Context

West works best when `.agents/product-marketing.md` exists. Run the product-marketing workflow (6.9) first to create it. All roles read this file automatically before starting any task.
